# Rohit Srivastava — Portfolio

Personal portfolio / resume site for Rohit Srivastava, AI Product Manager.

The site is a single self-contained static page (`index.html`) with no build step,
so any static web host can serve it as-is.

## Live site (GitHub Pages)

Once GitHub Pages is enabled (see below), the site is available at:

**https://spirit9966.github.io/Rohit_Srivastava.github.io/**

## Hosting options

### Option 1 — GitHub Pages (free, no provider needed)

1. On GitHub, open the repository → **Settings** → **Pages**.
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
3. Choose branch **`main`** and folder **`/ (root)`**, then **Save**.
4. After a minute or two the URL above goes live. Share that link for reviews.

### Option 2 — External hosting provider

Share these details with your hosting provider:

| Item | Value |
| --- | --- |
| Repository | https://github.com/Spirit9966/Rohit_Srivastava.github.io |
| Clone URL | `https://github.com/Spirit9966/Rohit_Srivastava.github.io.git` |
| Branch | `main` |
| Site type | Static HTML (no framework) |
| Build command | *none* |
| Publish / output directory | `/` (repository root) |
| Entry file | `index.html` |

Providers such as Netlify, Vercel, Cloudflare Pages, or a cPanel/FTP host work:

- **Netlify / Vercel / Cloudflare Pages:** "Import from GitHub", pick this repo,
  leave the build command empty, and set the output directory to the root.
- **cPanel / FTP hosting:** upload `index.html` into `public_html/`.

### Custom domain (optional)

To use your own domain (e.g. `www.yourname.com`), add it in the provider's
domain settings (or GitHub **Settings → Pages → Custom domain**) and create the
DNS records the provider tells you to.
